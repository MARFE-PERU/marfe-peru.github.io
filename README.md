# MARFÉ — Catálogo digital

Sitio estático preparado para GitHub Pages.

## Contenido
- `index.html`: página principal y catálogo.
- `css/styles.css`: estilos responsive.
- `js/main.js`: menú móvil y galerías de fotografías.
- `images/logo/`: logotipo original de MARFÉ.
- `images/productos/`: fotografías originales proporcionadas para el catálogo.

## Publicar en GitHub Pages
1. Crea un repositorio llamado `marfe-peru.github.io` dentro de la organización `marfe-peru`.
2. Sube el contenido de esta carpeta a la raíz del repositorio (no subas la carpeta contenedora como una subcarpeta).
3. En Settings → Pages, selecciona Deploy from a branch, rama `main`, carpeta `/ (root)`.
4. Guarda y espera la publicación.
